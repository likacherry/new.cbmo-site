# ЦБ МО — сайт

Статическая версия для GitHub Pages. Публикация: Settings → Pages → Deploy from a branch → main → /(root).

Публичный адрес после включения: https://likacherry.github.io/new.cbmo-site/

Справочник содержит демонстрационные назначения учреждений. Для общей серверной загрузки таблиц и обработки форм нужен backend; GitHub Pages публикует только статический интерфейс.

Документы ТЗ и рабочие материалы не включены.
